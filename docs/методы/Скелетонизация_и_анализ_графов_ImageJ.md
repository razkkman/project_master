# Топологическая скелетонизация и графовый анализ в ImageJ

Сложная трехмерная геометрия порового пространства в нанопористых материалах с трудом поддается аналитическому описанию методами евклидовой геометрии. Для компактного представления пространственной архитектоники поровых каналов в диссертации применен метод **топологической скелетонизации (медиального истончения)** с последующим анализом графов в среде ImageJ (Fiji).

---

## 1. Алгоритм построения 3D скелетона (Skeletonize3D)

Скелетонизация порового пространства заключается в редукции трехмерных каналов к их медиальной осевой линии толщиной строго в один воксель.

В среде ImageJ для этого используется плагин **Skeletonize3D**:
- Реализует модифицированный 3D алгоритм Ли-Кашъяпа-Чу (Lee-Kashyap-Chu thinning algorithm).
- Послойно удаляет простые граничные воксели в 26-связной окрестности без изменения топологических инвариантов:
  - сохраняется число связных компонент (число Бетти $b_0$),
  - сохраняется число сквозных тоннелей и петель (число Бетти $b_1$),
  - сохраняется число изолированных полостей (число Бетти $b_2$),
  - топологическая эйлерова характеристика $\chi = b_0 - b_1 + b_2$ остается строго неизменной.

## 2. Графовый анализ топологии: AnalyzeSkeleton (2D/3D)

После завершения скелетонизации полученный массив преобразуется в математический пространственный граф с помощью плагина **AnalyzeSkeleton (2D/3D)**.

### Классификация вокселей скелетона:
Каждый воксель скелетона анализируется по числу соседей $N_{26}$ в его кубической окрестности $3 \times 3 \times 3$:
1. **Концевые точки (End-points):** воксели, имеющие ровно одного соседа ($N_{26} = 1$). Они соответствуют тупиковым порам или выходам каналов на границу расчетной области.
2. **Узлы сочленения (Junction voxels):** воксели, имеющие $\ge 3$ соседей ($N_{26} \ge 3$). Это точки разветвления и пересечения поровых каналов.  
   Среди узлов ключевое значение имеют:
   - **Тройные соединения ($n_{3p}$):** узлы со связностью 3 (слияние трех ветвей).
   - **Четверные соединения ($n_{4p}$):** узлы со связностью 4 (крестообразные пересечения).
   - **Соединения высших порядков ($n_{other}$):** узлы со связностью $\ge 5$.
3. **Воксели ветвей (Slab voxels):** регулярные внутренние точки каналов, имеющие ровно двух соседей ($N_{26} = 2$). Они формируют ребра (ветви) графа.

## 3. Выходные параметры и структура данных

Плагин AnalyzeSkeleton экспортирует две базовые таблицы результатов:

### Таблица `*_Branch_info.csv` (информация по ветвям):
Содержит индивидуальные метрики для каждого сегмента (ветви) скелетона:
- `Skeleton ID` — идентификатор компоненты связности скелетона,
- `Branch length` — фактическая длина ветви вдоль воксельного пути скелетона ($d_{branch}$),
- `Euclidean distance` — прямое расстояние между концевыми узлами ветви в евклидовом пространстве ($d_{euclid}$),
- Координаты начальной и конечной вершин $(x_1, y_1, z_1)$ и $(x_2, y_2, z_2)$.

### Таблица `*_Results.csv` (сводная топология скелетона):
Содержит интегральные топологические характеристики:
- `# Branches` — общее число ветвей в графе,
- `# Junctions` — общее число узловых точек,
- `# End-point voxels` — количество тупиковых точек,
- `# Triple points` ($n_{3p}$) — количество тройных соединений,
- `# Quadruple points` ($n_{4p}$) — количество четверных соединений,
- `Average branch length` — средняя длина ветви.

## 4. Использование в расчетных модулях диссертации

Экспортированные CSV-файлы (сохраненные в `data/skeletons/`) загружаются и обрабатываются расчетными скриптами проекта:
- `src/Skeleton_tau.py` — расчет кривизны и тортуозности ветвей $\overline{\tau} = \frac{1}{n} \sum \frac{d_{branch}}{d_{euclid}}$.
- `src/Skeleton_junctions.py` — вычисление нормированного количества тройных узлов $W_{3p} = \frac{n_{3p}}{V_{solid}}$.
- `src/Skeleton_Z.py` — расчет координационных чисел ветвления $Z$ и $Z_{norm}$.
