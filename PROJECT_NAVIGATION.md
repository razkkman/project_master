## 📊 Паспорт обучающего набора данных (`porous_materials_ml_dataset.csv`)

Файл расположен в: [`data/processed/porous_materials_ml_dataset.csv`](data/processed/porous_materials_ml_dataset.csv)

* **Количество объектов (строк):** 534
* **Количество колонок:** 26 (17 числовых предикторов, 1 целевая переменная, 8 метаданных)
* **Пропущенные значения (NaN):** 0
* **Дубликаты:** 0
* **Материалы (7 базовых классов):**
  1. `Si12` — нанопористый травленый кремний (размер пор 12 нм)
  2. `Si21` — нанопористый кремний (размер пор 21 нм)
  3. `Si26` — нанопористый кремний (размер пор 26 нм)
  4. `KIT6` — упорядоченная биконтинуальная гироидная мезофаза (пр. группа $Ia3d$)
  5. `SBA15` — упорядоченная мезопористая фаза с гексагональными цилиндрическими порами
  6. `Coreshell-9` — наночастицы структуры ядро-оболочка (оболочка 9 нм)
  7. `Coreshell-16` — наночастицы ядро-оболочка (оболочка 16 нм)

### Ключевые поля датасета:
| Колонка | Тип | Описание |
| :--- | :--- | :--- |
| `ssa_bet_target` | **Target (y)** | Истинное физическое значение удельной площади БЭТ (м²/г) из криосорбционного эксперимента |
| `ssa_mc_modified` | Feature (X) | Базовый численно рассчитанный показатель площади Marching Cubes (м²/г) |
| `ssa_direct_method` | Feature (X) | Расчет удельной площади прямым методом фазовых переходов (м²/г) |
| `porosity` | Feature (X) | Пористость исследуемого суб-объема $\varphi \in [0.20 \dots 0.85]$ |
| `voxel_size_nm` | Feature (X) | Физический линейный размер вокселя томографической съемки $h$ (нм) |
| `w3p_density` | Feature (X) | Плотность тройных узлов ветвления скелетона пор $W_{3p}$ ($10^{25}$ м⁻³) |
| `tortuosity_tau` | Feature (X) | Извилистость каналов (гидравлическая тортуозность скелетона $\tau$) |
| `coordination_z` | Feature (X) | Среднее координационное число ветвления узлов скелетона $Z$ |
| `omega_other` | Feature (X) | Плотность нерегулярных узловых сочленений сетки пор |
| `scale_factor` | Meta | Коэффициент масштабирования сетки $k \in [0.70 \dots 1.00]$ |
| `material` | Meta | Текстовый идентификатор класса наноматериала |

Оценка на отложенной тестовой выборке (107 объектов, 20%):
