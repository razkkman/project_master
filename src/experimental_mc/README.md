# Экспериментальная ветка: Модификации метода Marching Cubes (Enhanced MC)

## 📌 Назначение
Данная папка (`/src/experimental_mc`) представляет собой **изолированную экспериментальную ветку** для исследования и разработки модификаций алгоритма Marching Cubes с целью повышения точности расчета удельной площади поверхности (SSA) и максимального приближения к данным физического эксперимента низкотемпературной адсорбции азота (метод БЭТ).

> [!IMPORTANT] Изоляция от базового кода
> Все исходные авторские модули в папке `src/methods/` (включая `marching_cubes.py` и таблицы `mc_tables.py`) остаются **полностью неизменными**, сохраняя 100% воспроизводимость оригинальных авторских расчетов диссертации.

---

## 🔬 Физические причины расхождений классического MC и эксперимента БЭТ

При сравнении расчетной SSA методом Marching Cubes с экспериментом БЭТ наблюдаются закономерные отклонения:
1. **Завышение площади для большинства мезоструктур (+15..+20%):**
   - На калибровочной сфере диаметром 15–29 вокселей ошибка триангуляции MC составляет ~34.7% (Глава 3.1).
   - В реальных пористых средах плоские треугольные фасетки, секущие ребра куба посередине, систематически дают избыточную площадь по сравнению с гладкой физической межфазной границей (эффект дискретной шероховатости сетки).
2. **Занижение площади для мелкопористых стохастических сред (Si12, $d_{pore} \approx 12$ нм):**
   - При размере вокселя 1.6 нм и шаге ячеек Marching Cubes 2 вокселя ($A = 3.2$ нм) на диаметр поры приходится всего 3–4 ячейки.
   - Дискретная сетка срезает внутреннюю суб-воксельную шероховатость пор, приводя к занижению расчетной площади относительно БЭТ.

## 🛠️ Внедренные модификации (`EnhancedMarchingCubesCalculator`)

В классе `EnhancedMarchingCubesCalculator` реализован комплекс физико-математических улучшений:
1. **Калибровка кривизны фасеток (`curvature_correction`):**
   - Компенсирует систематическое завышение площади дискретными треугольниками с помощью калибровочного коэффициента ($C_{geom} \approx 0.8658$), согласованного с аналитическим бенчмарком сферы.
2. **Адаптивное восстановление суб-воксельной шероховатости (`adaptive_roughness`):**
   - Вводит масштабный поправочный коэффициент для структур с узкими порами (Si12), восстанавливая эффективную сорбционную поверхность.
3. **Устранение фазового смещения сэмплирования (`phase_averaging`):**
   - Опциональное усреднение площади и объема по 8 возможным фазовым сдвигам сетки кубов $(\Delta z, \Delta y, \Delta x) \in \{0, 1\}^3$.
4. **Фильтрация недоступных микропор (`filter_inaccessible`):**
   - Исключение изолированных замкнутых внутренних пустот, в которые молекулы $N_2$ ($d = 0.354$ нм) физически не могут проникнуть.

## 🚀 Как запустить сравнение

### 1. Прямой запуск сравнительного скрипта:
```powershell
python src/experimental_mc/compare_mc.py
```
Скрипт выполнит расчет по всем 7 структурам, выведет сравнительную таблицу погрешностей $\Delta_{BET}$ и сохранит график в `docs/figures/Figure_MC_comparison_versions.png`.

### 2. Через главное интерактивное меню проекта:
```powershell
python src/main.py
```
Перейдите в раздел `[1] 📊 Расчет удельной площади поверхности` -> `[5] Экспериментальная модификация Marching Cubes`.
