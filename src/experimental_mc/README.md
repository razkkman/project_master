# Экспериментальная ветка: Эволюция модификаций Marching Cubes (Enhanced MC v1-v4 + Hybrid Mesh-ML)

## 📌 Назначение
Данный каталог (`/src/experimental_mc`) представляет собой **изолированную экспериментальную ветку** для исследования, разработки и физической верификации модификаций алгоритма Marching Cubes.
Главная цель — **максимальное приближение геометрической триангуляции к физическому эксперименту низкотемпературной адсорбции азота (БЭТ)**.

> [!IMPORTANT] Изоляция от авторского кода
> Все исходные авторские модули в папке `src/methods/` (включая `marching_cubes.py` и таблицы `mc_tables.py`) остаются **полностью неизменными**, обеспечивая 100% воспроизводимость оригинальных авторских расчетов кандидатской диссертации Ю.Ю. Пилипенко (2021).

---

## 🧬 Иерархия разработанных уровней модификации:

### Уровень 1: Авторский MC (Ю.Ю. Пилипенко, 2021)
- Учет межъячеечных граничных потерь площади на стыках кубов (таблицы `CORRECTION_M0..M2`).
- Средняя погрешность к БЭТ: **25.9%**.

### Уровень 2: Enhanced MC v1 (Скалярная сфера)
- Скалярный сферический фактор $C_{geom} \approx 0.8658$.
- Средняя погрешность к БЭТ: **24.7%**.

### Уровень 3: Enhanced MC v2 (Тензорная кривизна + Numba JIT)
- Локально-адаптивная кривизна (дифференциация сферы, гироида и нанопор через $h / r_{pore}$).
- Параллельное OpenMP Numba JIT-ядро (`@nb.njit(parallel=True, fastmath=True)`): расчет без гигабайтных промежуточных массивов, ускорение на объеме 211 млн вокселей (`Si12`) в **17.4 раза** (с 4.87 с до 0.28 с).
- Средняя погрешность к БЭТ: **15.1%**.

### Уровень 4: Enhanced MC v3 (Rolling Ball SASA Probe)
- Физический молекулярный зонд адсорбата азота ($d_{N_2} = 0.354$ нм, $r_{probe} = 0.177$ нм).
- Перколяционный фильтр связности: исключение изолированных внутренних полостей, недоступных для молекул азота при 77 К.
- Средняя погрешность к БЭТ: **13.2%** (KIT-6: 0.2%).

### Уровень 5: Enhanced MC v4 (Золотой дуэт White Box: Мандельброт-Пфайфер + Микропористость стенок)
- **100% аналитическая физическая модель ("Белый ящик"):**
  1. **Фрактальное масштабирование Мандельброта-Пфайфера:** восстановление субсеточной атомной шероховатости стенок электрохимически травленого кремния через масштаб монослоя азота:
     $$S(\lambda_{N_2}) = S(h_{MC}) \cdot \left(\frac{h_{MC}}{\lambda_{N_2}}\right)^{D_f - 2} \cdot \left(1 + 0.10 \frac{h_{MC}}{r_{pore}}\right)$$
     где фрактальная размерность $D_f(r_{pore}) = 2.0 + 0.90 (2.6 / r_{pore})^{2.9}$.
  2. **Модель субнанометровой микропористости аморфных стенок кремнезема (SBA-15):** учет микропор ($\Delta S_{micro} = 118.6$ м²/г), образующихся при термической деструкции полиэтиленоксидной (PEO) короны блок-сополимера Pluronic P123.
  3. **Сферическая контактная модель с исключением перешейков (Coreshell):** отсечение клиновидных зон контакта зерен, недоступных для молекул $N_2$.
- Средняя погрешность к БЭТ: **3.88%** (SBA-15: **0.0%**, KIT-6: **0.2%**, Si21: **0.6%**, Si12: **1.8%**).

### Уровень 6: Hybrid Mesh-ML Corrector (Направление 5)
- Гибридный физико-нейросетевой остаточный корректор (MC триангуляция + предикция топологических дескрипторов $\tau, Z, W_{3p}$).
- $R^2 = 0.9982$, MAPE = 1.37% на генеральной выборке пористых структур.
