# Данные исследований и экспериментальные структуры

В данной директории содержатся трехмерные данные пористых сред, результаты топологической скелетонизации и калибровочные 3D-модели:

- `structures/` — Стеки двумерных бинаризированных микрофотографий в формате TIFF, полученные методом FIB-SEM томографии:
  - `Si12`, `Si21`, `Si26` — мезопористые кремниевые структуры с различным временем травления и диаметрами пор (12 нм, 21 нм, 26 нм).
  - `SBA15` — упорядоченная гексагональная структура мезопор.
  - `KIT6` — упорядоченная кубическая гироидная структура мезопор.
  - `Coreshell9`, `Coreshell16` — мезопористые частицы ядро-оболочка (Core-Shell) с толщиной оболочки 9 нм и 16 нм.
  - Подпапки с суффиксами `-0.7`, `-0.75`, `-0.8`, `-0.85`, `-0.9`, `-0.95` содержат ремасштабированные стеки для проверки сеточной сходимости.
- `skeletons/` — Результаты скелетонизации в ImageJ (плагины Skeletonize3D / AnalyzeSkeleton):
  - `*_Branch_info.csv` — детальная информация по каждой ветви скелетона (длина ветви, евклидово расстояние, координаты узлов).
  - `*_Results.csv` — агрегированные характеристики скелетона (число ветвей, число соединений, тройные, четверные узлы).
- `models/` — Калибровочные 3D-объекты (сфера, цилиндр) в формате Wavefront OBJ/MTL.
- `research/` — Сводные таблицы физических параметров (`Description.txt`), коэффициенты регрессии (`Regression.xlsx`), данные сорбционных гистерезисов из литературы (`two_graphs_from_paper.*`).
- `processed/` — Бинарные файлы сериализации Python (`.pickle`) с промежуточными и итоговыми расчетными матрицами SSA, координационных чисел и тортуозности.
